# Lumen — трекер привычек

Веб-приложение для создания и отслеживания привычек.

## Возможности

- создание привычек;
- выбор цели, дней недели и времени;
- отметка выполнения на сегодня;
- расчёт дневного, недельного и месячного прогресса;
- серия выполненных дней;
- фильтрация привычек по целям;
- редактирование и удаление привычек;
- сохранение данных в localStorage;
- адаптивный интерфейс.

## Технологии

- HTML;
- CSS;
- JavaScript;
- ES Modules;
- localStorage.

## Запуск

1. Склонировать репозиторий.
2. Открыть папку проекта в VS Code.
3. Запустить `index.html` через Live Server.

## Структура проекта

- `index.html` — главная страница и привычки на сегодня;
- `habit.html` — список, фильтрация и редактирование привычек;
- `calendar.html` — календарь и статистика;
- `script.js`, `habit.js`, `calendar.js` — логика страниц;
- `storage.js` — работа с localStorage;
- `function.js` — общие функции для дат и статистики.
